Open Easy Kit — 开源 · 易用 · 工具集合

37 个独立发版的 Go 模块：微工具库、日志与可观测门面、注册发现、HTTP/RPC 生态、应用引导。 按需取用一个，或组全套骨架；每仓独立 SemVer、独立 CI、零强制捆绑。

go get oekit 浏览 38 个仓库 →

Open开源

全部 MIT 协议，源码即文档。38 个仓库全部公开、可审计、可 fork——不锁平台，不玩闭源阉割。

Easy易用

每个模块只做一件事，import 即用；微库零依赖或至多一条内部依赖，不会为了一个字符串函数拖进整个框架。

Kit工具集合

从 errors/stringx 微库到 Hertz/Kitex 生态适配器，同套规范同套接口分层，既能单点取用也能组全套骨架。

快速开始 按需取用，一个 import 就能跑

# 只要一个微库
go get github.com/oekit/stringx@latest

# 日志 + 追踪 + 注册发现
go get github.com/oekit/logx github.com/oekit/tracing github.com/oekit/registry

# HTTP 服务全家（中间件栈 + Hertz 运行时）
go get github.com/oekit/middleware github.com/oekit/hertz
package main

import "github.com/oekit/logx"

var svcLog = logx.WithService("my-service")

func main() {
    svcLog.Info("hello oekit", "version", 1)
}
